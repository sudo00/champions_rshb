## Ограничения

- Отказ для отсутствующего в каталоге вина и вероятности уверенности не откалиброваны.
- Один процесс worker на GPU; дополнительные процессы повторно загрузят модели.
- Android-клиенту требуется polling, обработка nullable-полей и отключение mock-подстановки при ошибках.
- Тесты производительности относятся к этой GPU и последовательным запросам.
